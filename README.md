## ▶️ Como Usar

Para rodar os notebooks / projetos:

1. Clone o repositório:
```bash
git clone https://github.com/caiodantass/DataScience_Projects.git
```

2. Entre na pasta:
```bash
cd DataScience_Projects
```

3. Abra os notebooks com Jupyter:
```bash
jupyter notebook
```

4. Instale dependências (caso necessário):
```bash
pip install -r requirements.txt
```
